# Field Intelligence Frontend Redesign

Field-first UI/UX replacement for the existing Field Intelligence backend.

Replace the existing:
- static/index.html
- static/app.js
- static/style.css

This frontend is designed for one-hand field use, outdoor readability, fast capture, map-first discovery, voice input, property intelligence, planning, team intelligence and AI queries.

It expects the existing FastAPI endpoints used by the project, including:
- /api/bootstrap
- /api/nearby
- /api/visits
- /api/ask

Do not upload API keys or .env files.
